Synced folders

Storage — conflicts + archived versions

Conflict copies sit next to the winning file (kept forever until you resolve them). Archived versions live in the hidden .sfx-versions area. Per-folder you can clear archived versions from the folder's detail panel.

Event history

The event log grows forever with routine records (transfers, skips, connectivity). You can either prune it automatically on a schedule, or use the Archive… button in the Event history header for a one-off manual archive. Open attention/conflict items are never auto-pruned — only routine logs older than the chosen age are removed.

Alerts

Page-worthy conditions (disk full, share unavailable, peer offline, deletion guard, corrupt-index rebuild) are posted here. Use an ntfy topic URL (https://ntfy.sh/<topic>) or a generic webhook that accepts JSON {title, message, tags}.
